# Roadmap

## 0.1 - Public foundation

- Lighter public order book and trades
- Price ladder, Footprint, Tape, and cumulative Delta
- Mock order lifecycle and risk gates
- Public execution adapter contract

## 0.2 - Research workflow

- Market-data recording and deterministic replay
- Footprint imbalance and absorption studies
- Session statistics and exportable research results
- More unit and browser tests

## 0.3 - Adapter ecosystem

- Versioned market-data and execution contracts
- Reference adapter test kit
- Additional venue adapters contributed independently
- Tenant-aware gateway reference architecture

Hosted live execution will be released only after authorization, tenant
isolation, idempotency, audit, and risk controls are verified.
