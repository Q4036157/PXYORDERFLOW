# UI 对标

## 布局

- 顶栏：账户选择（live/demo）| 合约 | OF_TRADING 状态
- 左：自有 K 线 + footprint（量 / 笔 / delta）
- 右：价格梯子（买量 | 价格 | 卖量）
- 下/浮：下单条数量、post-only 等
- 侧：Time & Sales

## 交互

- 点 **买列** → 限价买 @ 该价，qty 取下单条
- 点 **卖列** → 限价卖 @ 该价
- 己单标记；单击可撤该单
- **全撤**：确认框明示可能含策略/跟单挂单 → `confirmed=true`

## 非目标

- 不复用现网投研/量化 K 线页
