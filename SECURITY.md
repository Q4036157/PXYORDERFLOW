# Security policy

Do not report vulnerabilities through public Issues when they could expose
credentials, account access, order routing, or tenant data.

Send a concise report to `4036157@qq.com` with reproduction steps and affected
versions. Do not include real API secrets or customer data.

The public repository contains no production credentials or private execution
gateway. Deployers are responsible for authentication, tenant authorization,
encrypted credential storage, network isolation, rate limits, and audit logs.
